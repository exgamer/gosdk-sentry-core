# Changelog

## [1.2.0]

Публичный API только дополнен (`SentryConfig.Masked`); код сервисов компилируется без правок.

### Добавлено

- `config.SentryConfig.Masked()` — копия конфига для печати, DSN заменён на `***`.
- Сквозной CorrelationID: тег `correlation_id` у события, если в `ctx` вызова `Capture` есть id корреляции
  (`sdkctx.CorrelationID`, gosdk-core); явный тег из `Options.Tags` главнее. Требуется gosdk-core v1.3.0.

### Исправлено

- Reporter отправляет событие через собственную копию hub: hub запроса из контекста
  (`sentry.GetHubFromContext`), без него — копию глобального. Раньше `WithScope` шёл по глобальному hub, и при
  параллельных запросах событие получало теги и контексты (в том числе данные сообщения) чужого события.
- В событие уходит ошибка целиком — вся цепочка `Unwrap`; раньше отправлялась только самая глубокая причина,
  контекст обёрток (`save order: ...`) терялся. Внешняя обёртка-маркер errorreporter (приходит при
  `Options.Force`) снимается.
- `Stop` ждёт отправки событий в пределах `ctx` остановки (`sentry.FlushWithContext`); без дедлайна у `ctx`
  — не дольше 2 с. Раньше — всегда до 2 с без учёта `ctx`.
- DSN не печатается в debug-дампе конфига (`LOG_LEVEL=debug`) — вместо него `***`.

### ⚠️ Изменения поведения

- События получают `environment` = `APP_ENV`, `release` = `APP_VERSION`, `server_name` = `CONTAINER_NAME`
  (если значение задано). Заданные `SENTRY_ENVIRONMENT`/`SENTRY_RELEASE` по-прежнему в силе. Фильтры и алерты
  в Sentry по `environment`/`release` начнут видеть эти значения: раньше было `production` по умолчанию
  sentry-go (или `SENTRY_ENVIRONMENT`), релиз — автоопределение sentry-go.
- В событие уходит вся цепочка исключений (`Unwrap`) вместо одной корневой причины. Заголовок issue — тип
  внешней ошибки цепочки (например `*fmt.wrapError` или `*exception.HttpException`), а не самой глубокой
  причины; причина видна в цепочке исключений события. Группировка в Sentry меняется: после деплоя часть
  событий уже известных ошибок соберётся в новые issues (старые перестанут пополняться) — учтите это
  в алертах и при разборе.
- Теги hub запроса (например, выставленные sentry-middleware) попадают в событие, отправленное с этим `ctx`.
